# Требования к исходному коду

Редакция: **09.05.2026**

## Форматирование кода Python

* Наименования модулей и пакетов: `snake_case`;

* Наименования классов: `PascalCase`;

* Наименования методов, функций, имён переменных: `snake_case`;

* Наименования констант: `SCREAMING_SNAKE_CASE`.

### Наименование тестов

* В пакете `tests` находятся пакеты `test_{group}`, каждый из которых содержит тесты для определённой группы классов - репозиториев, сервисов, менеджеров и т.д.

* В пакетах `test_{group}` находятся модули `test_{class_name}.py`, каждый из которых содержит тесты одного класса.

* В каждом модуле находится один класс `Test{ClassName}`.

* Методы класса тестируют одну функцию или метод класса.

* Наименование методов-тестов:

  * Имя теста состоит из 3-х частей, разделяемых двойными подчёркиваниями:

    1. имя проверяемого метода;

    2. сценарий, в котором тестируется метод;

    3. ожидаемое поведение или результат при вызове сценария.

  * Имя пишется в `snake_case`, без допольнительных разделителей или форматирования.

* Каждый тест содержит структуру:

  * Подготовка (Arrange);

  * Действие (Act);

  * Проверка (Assert).

* Каждый тест имеет пояснения в комментариях.
